A loud kit for a working forum

06

Wiring it into Angular

ng-brutalism ships the primitives; this sheet decides what each colour means in a forum. Install it, then override only the semantic tokens.

src/styles.css
@import "tailwindcss";
@import "@ng-brutalism/ui/styles.css";

/* Forum semantics — the only overrides we need */
:root {
  --nb-primary: #ff90e8;   /* post, submit, liked */
  --nb-secondary: #c8a2ff; /* moderator, author */
  --nb-accent: #8ae9ff;    /* active filter, tab */
  --nb-warning: #ff9c42;   /* misleading-info flag */
  --nb-success: #63e6be;   /* answered */
  --nb-danger: #ff4f8a;    /* delete, field error */
  --nb-radius: 0rem;
  --nb-border-width: 2px;
}

Yours to build
Six components carry the app: PostCard, LikeButton, CommentItem, FilterSheet, BottomNav, AppShell. Compose each from nb primitives — don't restyle them.
Theirs to provide
nbSurface, nbSection, nbStack, nbCluster, nbSplit, nbButton, nbIconButton, nbChip, nbCallout, nbBadge, nbInput, nbTextarea, nbSelect, nbAvatarGroup, nbStatusDot cover everything above.
One breakpoint
At md (768px) bottom tabs become a left rail and the feed gains a sidebar. Cards are identical at both widths. Below it: single column, 44px minimum tap targets.
Requirements
Angular 21, Tailwind v4, Node 20.19+. Earlier Angular versions are not supported. Install with ng add @ng-brutalism/ui.
